John Personal Assistant. Last updated: 14 October 2026.

1. About this policy

John Personal Assistant ("the assistant") is a private, personal AI assistant built and used by a single individual, its developer and owner ("the owner"). It is not offered to the public and has no other users. This policy explains how the assistant accesses, uses, stores and shares Google user data, which in practice is the owner's own data from the owner's own Google accounts.

2. Google data the assistant can access

The assistant is connected to two Google accounts, both belonging to the owner, using read-only permissions only:

AccountDataGoogle OAuth scope
Personal account Gmail (read) https://www.googleapis.com/auth/gmail.readonly
Personal account Google Drive (read) https://www.googleapis.com/auth/drive.readonly
Personal account Google Docs (read) https://www.googleapis.com/auth/documents.readonly
Work account Gmail (read) https://www.googleapis.com/auth/gmail.readonly
Work account Google Calendar (read) https://www.googleapis.com/auth/calendar.readonly

The assistant also receives the basic account identifiers (openid and userinfo.email) that Google includes when an account is connected, so it can tell the two accounts apart.

The assistant is configured so that it can only search and read messages, files, documents and calendar events. It cannot send email or create, edit or delete any Google data through these connections.

3. How the data is used

Google data is used only to provide the owner's own assistant features: answering the owner's requests (for example, looking up an email, a document or the next calendar event) and preparing briefings and reminders for the owner. Data is retrieved when the owner asks for it or when a scheduled briefing runs. The data is not used for advertising, is not sold, and is not used to determine creditworthiness or for lending. The owner does not use Google user data to develop or train generalised AI or machine-learning models.

4. Processing by other services

To answer requests, the assistant software runs on a private server operated by the owner (rented from a hosting provider). When Google data is needed to answer a request, the relevant content is sent to an AI model provider (Anthropic, the maker of the Claude models) for processing, and the assistant's replies are delivered to the owner through a private chat service (Discord). These providers process the data only as part of delivering the assistant's responses to the owner, and they handle that data under their own terms and privacy policies, including their own retention practices, which the owner does not control. Google user data is not shared with any other third party, and is not shared for advertising or data brokering.

5. Storage and retention

  • Credentials: the access tokens that let the assistant read the connected Google accounts are stored on the owner's private server. They can be deleted by the owner at any time, which ends the assistant's access.
  • Content: the assistant does not maintain a separate copy or archive of the owner's Gmail, Drive, Docs or Calendar. However, parts of Google data that the assistant retrieves can appear in its working context, conversation history, or short notes it keeps on the owner's server in order to give continuity between conversations, and in the chat service used to talk to it. The owner can delete this history and these notes at any time.

6. Who can see the data

Only the owner has access to the assistant and to the data it retrieves. No other person reads Google user data, except where it is necessary for security purposes (for example, investigating abuse or a bug), to comply with applicable law, or where the owner has given explicit consent.

7. Security

The assistant runs on a private server operated by the owner, and the Google connections are limited to read-only scopes and to the specific functions listed above. No system is perfectly secure, and the owner aims to take reasonable steps to keep the server and credentials protected.

8. Google API Services User Data Policy

The assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Control and revoking access

The owner retains full control of both connected Google accounts. Access can be revoked at any time at myaccount.google.com/permissions, by removing the assistant from the list of third-party apps with access to the account, and by deleting the stored credentials from the server. The owner can also delete the assistant's history and notes at any time.

10. Changes to this policy

If the assistant's Google integrations change, this policy will be updated before the change takes effect, and the "last updated" date above will change.

11. Contact

Questions about this policy can be raised by opening an issue in the GitHub repository that hosts this site.
